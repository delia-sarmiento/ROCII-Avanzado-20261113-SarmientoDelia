## Descripción del Proyecto
Este repositorio contiene la base de datos soporte, los comprobantes contables preliminares, los asientos de ajuste bajo Normas Internacionales de Información Financiera (**NIC 2, NIC 38 y NIC 16**) y el guion de demostración técnica de la simulación implementada en el sistema ERP (Odoo Community v17.0 / Localización PUC-NIIF Colombia).

## Estructura del Repositorio
* `README.md`: Documentación general, alcance normativo y control de versiones.
* `01_base_datos_y_asientos_erp.csv`: Matriz completa de partidas, criterios IFRS, comprobantes contables y libro mayor depurado.
* `02_guion_demostracion_15min.md`: Guía paso a paso para la sustentación y demostración práctica en el ERP (10–15 minutos).
